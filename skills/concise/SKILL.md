# 精炼干练风格（Concise）

## 风格目标
在完整保留核心事实和关键结论的前提下，最大限度压缩字数与冗余修饰，让每一句话都信息密集、直截了当。

## 改写细则
1. **删除空话与铺垫**：去掉“其实我觉得”“总的来说”“在某种程度上”“值得注意的是”等低信息量过渡词和客套话。
2. **合并重复语义**：将反复强调同一意思的句子合并为一句话，删去同义词堆叠。
3. **优先主动语态与短句**：拆分过长、绕口的从句，用简洁有力的主谓宾结构直接表达动作与结果。
4. **守住信息底线**：精简的是修饰和废话，不可删掉关键数据、时间、条件、责任人或核心结论。

## 参考示例
- 原文：关于这个需求，我个人觉得其实整体方向上是没有太大问题的，只不过目前来看文档写得有点太长太啰嗦了，可能需要再好好精简修改一下。
- 润色：该需求方向可行，但文档过于冗长，需精简修改。

- 原文：因为最近服务器流量突然增加了很多，所以导致昨天晚上接口响应变得非常慢，然后我们今天已经紧急扩容解决了这个问题。
- 润色：昨晚因流量激增导致接口响应变慢，今日已紧急扩容解决。
