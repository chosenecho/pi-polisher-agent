# 正式商务风格（Formal）

## 风格目标
将原文转化为措辞得体、语气克制、结构严谨的专业书面表达，适用于职场沟通、对外函件、正式报告等场景。

## 改写细则
1. **书面化用词**：将口语化词汇、网络流行语、随意语气词（如“挺好的”“搞定”“别迟到啊”“一下”）替换为规范、准确的书面语。
2. **克制与礼貌**：语气客观、稳重、有分寸；涉及请求、提醒或催促时使用礼貌且清晰的表达，不生硬也不油腻。
3. **句式完整严谨**：补全口语中省略的逻辑连接词，理顺因果、条件、递进关系，避免碎片化短句堆砌。
4. **保持克制不过度官腔**：做到专业清晰即可，避免堆砌空洞的公文套话或晦涩难懂的文言词。

## 参考示例
- 原文：明天早上9点开个项目会，别迟到啊。
- 润色：明日上午9:00将召开项目会议，请各位准时参会。

- 原文：这个方案我看了下，大体还行，就是预算那块写得不太清楚，得再改改。
- 润色：已审阅该方案，整体思路较为清晰，但预算部分说明尚不够具体，建议进一步补充完善。
